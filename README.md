# Data Manipulation in Alteryx

Hands-on Alteryx workflows completed as part of the DataCamp **Data Manipulation in Alteryx** course. This repository demonstrates core data preparation, transformation, parsing, and workflow optimization techniques through real-world business scenarios from Velocity Inc.

## Overview

The projects in this repository focus on solving business questions using Alteryx Designer while applying industry-standard data manipulation techniques. The exercises cover combining datasets, joining information from multiple sources, parsing and transforming data, and optimizing workflow performance.
